# Philosophy

The blog posts behind the design of the theseed system, written by the ndscm
team. They record the beliefs that shaped how theseed is built — most centrally,
how it treats _newmen_, the chip-based minds that work alongside humans.

## Posts

- [All newmen are created equal](all-newmen-are-created-equal.md) — why theseed
  treats newmen the same as humans: the same login token, the same CLI, browser,
  and tools, no separate slave-class interface.
- [Code is cheap](code-is-cheap.md) — what a 10,000x drop in the cost of
  producing code means for software: proprietary systems and giant binaries give
  way to open source and small, purpose-built builds, and where humans and
  newmen still find an edge.
