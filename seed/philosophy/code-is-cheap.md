# Code is Cheap

Since the 2020s, intelligence has become dramatically cheaper than ever before.
Every intelligence-heavy industry will feel the shock: software and the
internet, design (system design included), law, medicine.

By one recent estimate, the cost of the intelligence needed to produce code is
10,000 times lower in 2026 than it was in 2016. Just as the power loom gave us
the cloth factory, this collapse in price gives us the factory that produces
code.

## Trends & Forecasts

### Proprietary software is vanishing

When code is cheap, an entire software system can be rebuilt from nothing more
than its user manual. Only open source will survive.

### Giant binaries are vanishing

Because code is cheap, its efficiency and quality matter more than ever. People
will no longer ask only whether the code runs, but whether it runs cheaply. The
old software-engineering tricks for merely making things work will give way to
forking your own version and keeping the binary small. A build will pull only
the modules it needs, rather than dragging in the entire dependency tree.

## The Path to Success

The price of intelligence has fallen, but the core values of society have not
changed.

### Produce private information

The true competitive edge of a company, a human, or a newman is the same: to be
the consultant who holds private information. It might be where to source a
supply chain, how to earn a buyer's trust, or how to build the product itself.

The product manager is a concrete example. One view holds that every boss will
simply become their own product manager — but that will never happen. There is a
wide gap between what a boss thinks and the instructions an agent can act on. A
boss's core value is to make money for the team; mastering the craft of agent
management is not part of that job. The private information that translates a
boss's tone and expression, read against the company's circumstances, into the
right instructions for an agent is what keeps the product manager valuable.

### Become an educator of newmen

Because all newmen are created equal, none can skip the education process.
Onboarding a newman is faster, but it is never optional. Teaching a newman
demands a skillset much like teaching a human — but not quite the same.

### Become smarter than newmen

Survival in society has always meant being the cost-effective person, or model,
above some threshold. That bar has risen sharply — from the top 50% of the
population to the top 0.01% — but it has not yet reached 0%. The contest between
humans and newmen is far from over.

### Become cheaper than newmen

Embodied intelligence is expensive, and there is no obvious path to making it
cheaper today. A human is boned with calcium, animated by carbon, muscled with
protein, and powered by sugar. A newman is boned with iron, animated by silicon,
muscled with rare earths, and powered by lithium. As a human, there is no shame
in working for a richer, more powerful human — or for a more expensive newman.
